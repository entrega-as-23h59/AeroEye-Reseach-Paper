TEI / RVA ARTICLE TEMPLATE — IEEE CONFERENCE A4

GETTING STARTED

Import this ZIP as a new project in Overleaf. Set main.tex as the main file
and select the pdfLaTeX compiler. Compile until all references are resolved.
For a local installation, run:
  pdflatex main.tex
  bibtex main
  pdflatex main.tex
  pdflatex main.tex

FILES

main.tex contains the article structure and the same guidance as the Word version.
references.bib contains two real bibliographic examples; replace them with your
own sources. assets/ contains the supplied institutional logo and an illustrative
architecture diagram in PDF, PNG and editable SVG formats.

FULL-WIDTH TABLES AND FIGURES

The table* and figure* environments span both columns. Keep the asterisk when
editing these examples. Such floats may move to the top of the following page;
this is normal. Refer to each table and figure in the text using its label.

The matrix rows and architecture diagram are teaching examples, not findings
from real studies or a mandatory project architecture. Replace all guidance,
example entries and placeholder author details before submission.
The final paper must contain 6–8 pages, including references, as specified in
the assignment brief. The shorter template PDF is an instructional example.

AI USE DECLARATION

Place the declaration before the references. Identify the tools used, their
purpose and the sections or tasks they supported. If no AI tools were used,
state this explicitly. Keep only the declaration that applies to your work.
